## N5 Goal

**Target: Recognize, read, write, and understand all 80 kanji.**

### Recommended routine

**5 kanji/day → 16 days**

For every kanji:

1. Learn the meaning.
2. Learn the main N5 reading.
3. Practice the stroke order.
4. Learn 2–3 common words.
5. Read the example words aloud.
6. Review previously learned kanji.
7. Mark the checkbox after you can recognize and read it confidently.

## Reference

The 80-kanji set in this file follows the commonly used JLPT N5 kanji list from JLPT Sensei. Because the JLPT does not publish an official fixed kanji/vocabulary list, this should be treated as an **N5 study reference**, not an official guaranteed exam list.
